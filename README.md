# T.C. Ev Ici Terlik Hukuku Genel Mudurlugu

## Terlik Ciftinin Resmi Bosanma Dilekcesi

Bu depo, sol terlik ile sag terlik arasindaki evlilik birligini **bilimsel, hukuki ve tamamen gereksiz** bir ciddiyetle sona erdirir.

Calisir. Ayakkabi degildir. Avukat degildir. Paspasin ustunde durur.

## Neden var?

Cunku evin icinde yillarca yan yana duran iki nesne, bir gun birbirine bakip "biz aslinda cift miydik yoksa sadece ayni ayagin kurbani miydik?" diye sormak zorundadir. Bu sorunun cevabi resmi evraktir.

## Kurulum

```bash
python3 bosanma.py
```

Baska bir sey kurmayin. Terlik zaten kurulu gelir. Bazen tek gelir.

## Ne yapar?

- Nafaka kalemlerini toplar
- Islak zemin sorumlulugunu reddeder
- Muhur basar
- Itiraz merciini paspas olarak ilan eder

Islak zeminde kayarsaniz suclu bu depo degildir. Suclu zemin sileceginin tatilidir.
